#Security Policy
Supported Versions
Security updates are provided for the latest release of Sentrys.

Version	Supported
Latest release	:whitecheckmark:
Older releases	:x:
Reporting a Vulnerability
If you discover a security vulnerability in Sentrys, please report it privately rather than opening a public GitHub issue.

Please include:

A clear description of the vulnerability
The affected version
Steps to reproduce the issue
The potential security impact
Any relevant logs, screenshots, or proof of concept
Reporting privately
Please use GitHub's private vulnerability reporting feature if it is enabled for this repository.

If private reporting is not available, contact the project maintainer privately through the contact information provided in the repository profile.

Please do not publicly disclose the vulnerability until it has been investigated and, if necessary, fixed.

Response
I will try to acknowledge vulnerability reports within 7 days.

After reviewing the report, I will determine whether the issue is a security vulnerability and, when appropriate, work on a fix and release.

Reports that are not considered security vulnerabilities may be closed with an explanation.

Scope
This policy applies to the Sentrys codebase and its official releases.

Sentrys is intended for authorized security testing and reconnaissance only. Users are responsible for ensuring that they have permission to scan or assess any target. :::
